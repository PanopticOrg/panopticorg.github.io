# Les recommandations

Un troisième outil de similarité sont les recommandations pour compléter un groupe existant. 

Il faut préalablement avoir groupé ses images par une propriété de type tags ou multi_tags puis, dans le menu des trois petits points d'un groupe, cliquer sur "Passer en vue recommandations":

![Alt text](../images/v1/reco-menu.png)

Cela ouvre alors la vue "Recommandations", qui propose une à une des images similaires à toutes les images du groupe source. On peut venir ensuite pour chaque image soit valider (coche verte) ou refuser (croix rouge). En validant une image cela va venir l'ajouter au groupe en lui assignant le tag du groupe. En la refusant, elle rejoint la liste noire et ne sera plus proposée.

![Alt text](../images/v1/reco-vue.png)

Sous l'image proposée, la vue affiche trois sections : les recommandations à venir, les images déjà présentes dans le groupe, et la liste noire. Le menu déroulant en haut de la vue permet de passer d'un groupe à un autre sans revenir à la grille, et la flèche circulaire de recharger les propositions.
